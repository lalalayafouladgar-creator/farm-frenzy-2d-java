# 🐔 Farm Frenzy 2D

A 2D farm management and time-strategy game inspired by **Farm Frenzy 2**, developed with **Java**.

## 🎮 About the Game

In this game, the player manages a farm, takes care of animals, collects and processes products, manages the warehouse, and completes different level objectives within a limited amount of time.

The game focuses on resource management, production chains, and time-based challenges.

## 🛠️ Technologies

## 🏗️ Architecture

The project follows the **MVC (Model-View-Controller)** architecture.

### Model

Contains the game entities, data, and core game logic.

### View

Contains the graphical user interface of the game.

### Controller

Handles user interactions and connects the View with the Model.

## 🎯 Main Features

* Animal management
* Animal feeding and production
* Product collection
* Product processing
* Warehouse management
* Selling products
* Farm economy
* Time-limited levels
* Level objectives and scoring
* Game progress persistence

## 🧵 Multithreading

The project uses Java's `ExecutorService` and thread pools to manage background game tasks.

Thread synchronization is used where multiple tasks access shared game resources.

## 💾 Data Persistence

Game progress and player-related information are stored using a database.

The project uses **MySQL** and **JDBC** for database communication.
